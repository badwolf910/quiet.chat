# Chapter & Hearth

A cozy independent-bookshop storefront built with Vite, Bootstrap's responsive grid, and prefixed Tailwind utilities.

## Development

Requires Node.js 20.19 or newer.

```sh
npm install
npm run dev
```

Vite prints the local URL when the development server is ready.

## Production build

```sh
npm run build
npm run preview
```

The static site is generated in `dist/`. GitHub Pages deploys that folder from the `main` branch through the workflow in `.github/workflows/pages.yml`.
